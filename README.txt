SAFA ENTERPRISES – React (Vite) project

Chalane ke liye (Node.js 18+ chahiye):
  npm install
  npm run dev        -> http://localhost:5173
  npm run build      -> "dist" folder hosting par upload karein

Edit kahan karein:
  src/config.js          -> phone, address, hours, map
  src/data/products.js   -> products add / edit / delete (img: naam ya /images/products/xyz.jpg)
  public/images/products -> product photos (apni asli photo isi folder me daalein)
  public/images/work-*   -> "My work" gallery photos (same naam se replace karein)
  src/styles.css         -> colors / design (top ke :root variables)
